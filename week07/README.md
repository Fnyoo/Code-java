## Programs

### 1. `CaseStudy1.java` — Senja Coffee Shop
- Price per cup: Rp18,000.
- A 10% discount applies when the purchase total is at least Rp100,000.
- Calculates the final payment and change.

Run:
```bash
javac code/CaseStudy1.java
java -cp code CaseStudy1
```

### 2. `CaseStudy2.java` — Student Achievement Award
- BELMAWA, BAKORMA, and independent competitions qualify only for 1st, 2nd, or 3rd place.
- PKM qualifies when the proposal is approved for funding.
- Other activity types do not qualify.
- Eligible students must upload four required documents; the program reports the number missing.

Run:
```bash
javac code/CaseStudy2.java
java -cp code CaseStudy2
```
